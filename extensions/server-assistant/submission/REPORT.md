## 1. 개발 배경과 목표

첫 근로·임대차·용역 계약을 접하는 사회초년생은 낯선 표현을 이해하고, 중요한 조건을 찾고, 서명 후 날짜를 관리하는 데 어려움을 겪을 수 있다. 본 작품은 원문 등록 → 내용 확인 → 분석 → 근거 확인 → 계약 보관 → 일정 등록의 흐름을 하나의 모바일 웹 화면에서 제공하는 것을 목표로 한다. 법률 판단이나 계약 안전성 보증을 목표로 하지 않는다.

## 2. 설계와 구현

기존 프로토타입의 네이비·골드·아이보리와 430px 모바일 화면, 카드, 단계별 분석, 달력·알림 설정을 유지했다. Python 표준 HTTP 서버, 순수 HTML/CSS/JavaScript, SQLite를 사용했다. 서버 API, 분석, 파일 추출, AI 어댑터, 저장 로직을 분리해 대학 1~2학년 수준에서 처리 흐름을 설명할 수 있도록 구성했다.

직접 입력, TXT, 텍스트 PDF를 실제로 읽고 사용자가 추출 원문을 수정한 다음 분석한다. 로컬 모드는 정규식과 사전을 이용해 조건 문장, 날짜, 확인 후보와 용어 설명을 제공한다. 요약은 원문 발췌이며 모든 항목에 원문 근거와 줄·문자 위치를 표시한다. 확인할 수 없는 기간·금액·지급 조건은 확인 불가로 표시한다.

실제 AI 사용을 위한 서버 측 Responses 호환 API 연결도 구현했다. API 키와 모델은 환경변수로 관리하고, 문서 내부 명령과 서버 지시를 분리하며, 응답 구조 및 인용의 원문 존재 여부를 검증한다. 이번 실행에서는 자격증명이 없어 유료 API 호출을 수행하지 않았다. 로컬 규칙 결과와 AI 설명을 구분하여 표시한다.

사용자가 분석 결과를 확인해 저장하면 계약 ID별 상세를 조회할 수 있다. 명시된 날짜를 일정 후보로 제시하고 사용자가 날짜와 이름을 확인·수정한 뒤 등록한다. 계약 삭제 시 연결 일정과 알림 기록도 외래키를 통해 삭제한다. 알림은 앱이 열린 동안 검사하고 DB 고유키로 같은 날 중복 표시를 줄인다.

## 3. 실험 설계

시연·규칙 개발 자료는 `samples/`의 가상 임대차·용역 계약이다. 평가 자료는 별도 `evaluation/data.json`의 12개 가상 문서와 정답 라벨이다. 규칙 초안 작성 후 평가 세트를 만들었으나 작성자가 규칙을 알고 있으므로 블라인드 검증이 아니다. 날짜·주의 탐지 규칙은 평가 결과를 보고 조정하지 않았다. 이후 조건 미정 문장의 확인 불가 표시를 보완했다.

날짜는 문서별 고유한 ISO 날짜 집합으로 비교했다. 주의 항목은 문서별 5종 확인 주제 존재 여부를 비교했다. 정밀도=TP/(TP+FP), 재현율=TP/(TP+FN), F1=2PR/(P+R)로 계산했다. 인용은 원문의 문자 범위와 정확히 일치하는지 검사했다. 처리 시간은 PDF·OCR·API·저장 시간을 제외한 규칙 분석 1회 실행 기준이다.

## 4. 실제 측정 결과

최종 정확한 실행 환경·시각·항목별 지표·처리 시간은 `evaluation/results.json`과 `docs/VALIDATION.md`를 기준으로 한다.

|평가|규모|결과|
|---|---|---|
|날짜 추출|12문서, 고유 날짜 11개|정밀도 1.0000 / 재현율 1.0000 / F1 1.0000|
|주의 항목 전체 micro|정답 15개|정밀도 1.0000 / 재현율 0.8000 / F1 0.8889|
|인용 존재·문자 범위|70회 인용 검사|70/70 일치|

표현이 바뀐 자동 연장·일방 변경·돈 돌려주기 문장을 키워드가 찾지 못했다. 이 한계는 평가 데이터에 그대로 남겼으며 성능을 높게 보이도록 정답을 수정하지 않았다. 인용 일치는 설명의 의미가 맞다는 증명이 아니다. 실제 계약 전체에 대한 정확도나 만족도를 추정하지 않았다. 사람 평가를 위한 기준표와 빈 CSV를 제공했으며 사람 평가 결과는 아직 없다.

## 5. 검증과 한계

단위·HTTP 테스트는 문서별 결과, 빈 입력, PDF 추출, OCR 미설치, AI 키 없음·시간 초과·잘못된 인용, 저장·수정·삭제와 연쇄 정리, 알림 중복 방지, 요청 출처·파일 접근 차단을 검사한다. 브라우저와 재시작 검증의 최종 실행 범위는 `docs/VALIDATION.md`에 기록한다.

OCR 연결은 Tesseract와 한국어/영어 언어 데이터를 설치한 환경에서 사용하도록 구성했으나 현재 실제 엔진이 없어 한국어 인식은 미검증이다. 브라우저 종료 중 푸시, 회원 인증, 암호화 저장, 운영 배포, DOCX 입력은 미구현이다. 날짜 자동 계산은 완전한 연월일을 추출하는 범위에 제한한다. AI 설명은 인용문이 있어도 의미 오류나 프롬프트 인젝션 위험이 남을 수 있다.

## 6. 기여 및 활용

사회초년생이 계약을 이해하고 중요한 날짜를 직접 관리하도록 돕는 흐름을 구현했다. 원문 근거와 확인 불가 표시, 가상 자료 구분, 규칙/AI 모드 구분으로 시연 결과의 해석 범위를 명확히 했다. 실제 사용자 연구와 전문 검토는 향후 과제로 남긴다.

실제 팀원별 기여는 `docs/TEAM.md`에 작성하고, AI 코딩 보조·외부 라이브러리·원본 UI 활용은 `docs/SOURCES.md`를 확인해 대회 규정에 맞게 공개한다. 본 문서는 학교 최종 결과보고서 서식을 대체하지 않는 편집 가능한 초안이다.
