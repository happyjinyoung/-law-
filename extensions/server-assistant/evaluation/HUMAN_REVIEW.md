# 요약·쉬운 설명 사람 평가

아직 평가자를 모집하거나 사람 점수를 측정하지 않았다. 아래 양식의 빈칸은 미평가 상태를 뜻한다. 사용자 만족도로 해석하지 않는다.

최소 2명이 각자 원문과 표시 결과를 비교한다. 데모와 실제 AI 모드는 별도 평가한다. 문서 ID, 모드, AI 모델 ID(해당 시), 버전, 평가자 익명 ID, 기준일을 기록한다. 개발 샘플과 평가 세트를 섞지 않는다. 평가에 사용할 원문은 별도 합성 문서를 추가해도 된다.

|항목|1점|2점|3점|4점|5점|
|---|---|---|---|---|---|
|원문 충실성|핵심 사실 조작|다수 왜곡|일부 오류|경미한 누락|근거와 정확히 일치|
|핵심 포함|대부분 누락|중요 조건 다수 누락|일부 핵심 포함|대부분 포함|명시된 주요 조건 모두 포함|
|쉬운 표현|더 어려움|전문용어 위주|일부 쉬움|대체로 쉬움|초심자가 바로 이해|
|근거 적합성|무관한 근거|연관 희박|일부 뒷받침|대체로 뒷받침|각 설명을 직접 뒷받침|
|불확실성 표시|안전/법률 확정|과도한 확신|일부 유보|대체로 적절|확인 불가와 범위를 명확히 표시|

숫자 평균만으로 결론 내지 말고 누락·오해·근거 불일치 사례를 기록한다. 법률 전문성 검증을 대신하지 않는다. CSV를 복사해 문서×평가자 한 행씩 작성하고 평가자 간 차이를 함께 보고한다.
