# 3~5분 시연

사전 준비: 서버 실행, 브라우저 확대율 100%, 창 너비 약 430px, API 키 없이 로컬 모드. 원문에 개인정보가 없는지 확인한다. 오래된 가상 시연 데이터는 UI에서 삭제할 수 있다.

|시간|조작|설명할 내용|
|---|---|---|
|0:00–0:30|홈 확인|사회초년생의 계약 이해와 서명 후 관리 문제, 4단계 흐름|
|0:30–1:10|분석 시작 → 가상 샘플 불러오기 → 원문 확인|샘플 표시, 이름·유형 편집, 원문 검토; 고정 결과가 아님|
|1:10–2:00|규칙 분석 → 요약·조건·위약금 근거 확인|로컬 모드 표시, 인용 줄·위치, 법률 안전 판정이 아님|
|2:00–2:50|계약 저장 → 해당 상세 → 날짜 후보|후보 날짜·용도를 확인하고 일정 이름·날짜 수정 후 등록|
|2:50–3:30|나의 계약 달력/목록 → 검색 → 상세|계약 ID 연결, 새로고침 후 저장·일정 유지|
|3:30–4:00|상담/검색 → 계약 선택 → 위약금 질문|관련 문장 검색은 AI 상담이 아님을 명시; 근거 없는 질문은 확인 불가|
|4:00–4:30|설정과 테스트 알림|표시 이름·사전일·시각 저장, 앱이 열린 동안만 알림|
|4:30–5:00|평가·한계 소개|12문서 합성 평가, 실제 계약 일반화 불가, AI 키·OCR 엔진 미설치 한계|

3분 시연은 상담·설정을 각 10초로 축약한다. 서로 다른 결과 확인은 두 번째 가상 용역 TXT를 업로드해 300,000원과 별도 기간이 나타나는 것을 보여준다. 실제 AI 연결을 시연하려면 미리 정상 계정과 모델로 검증해야 하며 이번 검증에서 성공했다고 소개하면 안 된다.
