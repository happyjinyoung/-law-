## 검증 제한

Tesseract 엔진과 kor/eng 데이터가 없어 실제 이미지·스캔 PDF OCR 결과는 실행하지 않았다. pypdfium2 렌더러 설치 상태 확인과 OCR 미설치 처리만 확인했다. AI 실제 호출에는 사용자 API 키·이용 가능한 모델과 비용 조건이 필요하다. 사용자의 실제 계약서와 개인정보는 검사에 사용하지 않았다. GitHub 원격 업로드·운영 배포는 수행하지 않았다.

초기 자동 테스트는 환경의 로컬 소켓 제한 때문에 막혔고, 네트워크 권한을 받은 뒤 실행했다. 통합 테스트가 빈 DELETE 요청의 JSON 처리 오류를 발견했고 수정 후 전체 테스트가 통과했다. 설치된 Edge는 자동화 실행에 실패해 작업용 Chromium을 별도로 내려받아 검증했다. 브라우저와 테스트 DB는 제출 ZIP에 포함하지 않는다.
